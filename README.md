# vk-tunnel
2 бота в vk экосистеме общяются и передают http запросы и ответы в конвентированно "человеками" данные
пример
curl http://google.com
бот клиент пишет
чел хлеб мем кек жопа сука
бот сервер читает
удоляет(если прочтенно)
передаёт рандомные слова и gif или png с скрытыми водяными знаками в виде QR кодов видео или текстовые документ или word документ
клиент конвертирует в код сайта
и отдаёт по локальному прокси
